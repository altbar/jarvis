# Что делать, если...

Агент, участник застрял. Найди ситуацию ниже и действуй. Если ситуации нет в списке или не помогло дважды - предложи участнику спросить в чате потока: там организаторы и такие же выпускники.

## ...я не понимаю, что такое терминал и куда вставлять команды

Это нормально, тут все впервые. Открой участнику ustanovka/terminal.md и проведи по нему: где открыть (он уже есть в системе, качать не надо), как вставить команду, как понять, что она отработала. И напомни: большинство команд ты выполняешь сам - участнику достаточно смотреть.

## ...доступ к моделям перестал работать

Признак: ошибки вида insufficient credits / 402 / лимит исчерпан.
1. Подписка на месяц включена в стоимость и активирована на твоем аккаунте MiniMax; ключ берешь сам в кабинете (ustanovka/klyuch-trening.md). Не активировалась или не входишь - напиши боту тренинга, разберемся.
2. Пока решаешь - оплата по факту у MiniMax (0,30 доллара за миллион токенов на входе) или free-модели OpenCode Zen: почти бесплатно.
3. Через месяц подписка кончится - переходи на свою: ustanovka/oplata-podpisok.md, minimax.md, kimi.md.
4. На будущее: тяжелые команды (совет директоров, разбор больших файлов) жгут лимит быстро - зови их по одной, не пачкой.

## ...установка не идет на Windows

1. Проверь: система 64-bit, есть права администратора, антивирус не съел установщик.
2. Не завелось за 10 минут - не воюй: подними руку, есть запасной путь (OpenCode остается рабочим инструментом весь тренинг, Hermes доставим позже или сразу на сервер в день 2).

## ...плагины Obsidian не включились / SmartScreen ругается / корпоративный ноутбук

1. Сначала обнови волт (синхронизация или свежее скачивание): текущая версия несет плагины в комплекте, в папке `.obsidian/plugins`. У тех, кто качал волт рано, их просто не было - это не поломка.
2. В Obsidian: Настройки -> Сторонние плагины (Community plugins) -> отключи ограниченный режим (Restricted mode / «Включить сторонние плагины») -> включи плагины из списка. На вопрос «доверять этому волту?» отвечай «доверять» - это наш волт.
3. SmartScreen при установке программ: «Подробнее» -> «Выполнить в любом случае».
4. Корпоративный ноутбук с политиками, которые запрещают установку: не воюй с ИТ-отделом на тренинге. База работает и без плагинов; включишь их дома или на личной машине. И это еще один довод за день 2: Hermes на своем сервере - чистая машина без чужих политик.

## ...Handy молчит или не распознаёт

Самая частая причина: **не скачана модель распознавания**. Settings -> Models -> Whisper Medium (492 МБ), дождись загрузки. Вторая: не выдан доступ к микрофону (Mac спрашивает при первом запуске). На Mac как альтернатива есть FluidVoice (github.com/altic-dev/FluidVoice); на Windows - только Handy.

## ...пропал интернет / Wi-Fi упал / что-то не открывается

1. Переподключись к Wi-Fi зала (имя и пароль бот прислал накануне вечером).
2. Проверь резервную сеть (объявят со сцены, если основная легла).
3. Если не открывается конкретный сервис - подними руку: возможно, нужен резервный маршрут, он есть.

## ...свежий почтовый ящик заблокирован

Это норма для новых Google-ящиков при подключении агента. Поэтому свежие Gmail не подключаем: берем свою рабочую почту с паролем приложения по инструкции ustanovka/pochta-yandex.md. Корпоративная почта с запретами - там же раздел, что делать.

## ...я отстал от группы

1. Не догоняй на слух: скажи мне (агенту) «продолжаем урок с шага, где остановился» - я поведу в твоем темпе.
2. После общей сверки застрявших разбирают индивидуально - подойди и скажи, где встал.
3. Пропущенный блок не страшен: все уроки лежат в базе, вечером можно пройти самому.

## ...запутался в меню настройки Hermes (визард)

Не воюй с экранами - настрой через своего агента: скажи OpenCode, что нужно поменять в Hermes, он сам поправит `~/.hermes/config.yaml` и `~/.hermes/.env` и перезапустит гейтвей (раздел «Настройка через агента» в ustanovka/hermes.md). Симптом «голосовухи не распознаются»: попроси агента выполнить `grep -i groq ~/.hermes/.env` - если в GROQ_API_KEY текст вместо ключа, визард промахнулся: впиши ключ, `hermes config set stt.provider groq`, `hermes gateway restart`.
Симптом «русская голосовуха распознается английской ерундой» («Hello, you hear me?»): работает локальный whisper с крошечной моделью base (агент мог поставить его сам) или не задан язык. Лечение: `hermes config set stt.provider groq` + `hermes config set stt.language ru` + `hermes gateway restart`.

## ...агент тупит на сложных задачах, хотя не завис

Первым делом проверь размышление модели: у MiniMax-M3 оно **выключено по умолчанию**. Скажи агенту: «включи adaptive thinking для MiniMax-M3 и подними max_tokens до 131072». Подробности и проверка - `ustanovka/minimax.md`, раздел про размышление. На подписке это бесплатно, тратится только время ответа.

## ...агент завис / думает бесконечно / делает не то

1. Останови текущую команду (Esc или стоп в интерфейсе). Если по расписанию он делает лишнее, `hermes pause` ставит на паузу все задачи разом, `hermes resume` возвращает.
2. Начни новую сессию/чат - контекст мог переполниться.
3. Сформулируй задачу заново одним коротким предложением: одна команда - одно действие.

## ...не создается Telegram-бот

- **«Invalid token format»** при вставке токена: ты вставил не тот ключ. Токен бота выглядит как `1234567890:AAEhB...` (цифры, двоеточие, буквы) - ключи доступа к моделям выглядят иначе. Возьми токен у @BotFather.
- **Лимит ботов** (Telegram дает до 20 на аккаунт): возьми токен существующего свободного бота (@BotFather -> /mybots -> API Token) или удали ненужного (/deletebot). Свободного - значит не подключенного к другому сервису.
- Ссылка из автоматического пути не кликается в терминале - скопируй ее в браузер, откроется Telegram.

## ...Джарвис в Telegram не отвечает

1. Проверь, что шлюз на сервере жив: попроси агента в OpenCode зайти на сервер и выполнить `systemctl --user status hermes-gateway` - нужно зелёное `active (running)`. Если Гермес у тебя пока на ноутбуке, ноутбук закрыт = Джарвис спит.
2. Проверь, что ты пишешь СВОЕМУ боту (тому, которого создал в BotFather), а не боту тренинга.
3. Перезапусти Hermes и напиши боту снова.
4. Сразу после `hermes update` бот замолчал - выполни `hermes gateway restart` и проверь статус ещё раз.
5. Если уже переехал на VPS и бот отвечает через раз или невпопад - на ноутбуке остался запущенный гейтвей: два Hermes с одним токеном отбирают сообщения друг у друга. Останови локальный (`hermes gateway stop` + снять из автозапуска), порядок - в ustanovka/hermes-na-vps.md.

## ...страшно грузить личные данные

Нормальный вопрос. Короткие правила: на тренинге грузи то, что не жалко; наружу агент ничего не отправляет без твоего «да»; полный разбор безопасности будет во второй день (uroki/den2-s3-research.md). Ключи и пароли не вставляй в чат с агентом никогда.
