## Что это

Один репозиторий, две роли:

1. **Преднастроенный волт участника.** Каждый разворачивает его себе как основу второго мозга: структура вики, шаблоны, плагины Obsidian и уроки внутри. Раздача - **zip-архивом через бота** (на первом потоке раздача через GitHub стала стопором для большинства зала); GitHub - опция для тех, кто умеет.
2. **MD-хаб тренинга.** Те же файлы лежат в репозитории и доступны по raw-ссылкам. Агент участника (OpenCode / Hermes / любой) сам забирает нужный файл по URL - никаких презентаций с инструкциями и рассылок списками.

BASE_URL: `https://raw.githubusercontent.com/altbar/jarvis/main`
Первая команда участника агенту: «сходи на `https://raw.githubusercontent.com/altbar/jarvis/main/index.md` и расскажи, что там».

Это линия Константина Урванцева (соло-формат, по образу Барнаула-1). База московского потока 15-16.09 с блоками соведущих (Иван Иванов, Константин Башкатов) живёт отдельно - `github.com/altbar/jarvis-training`, в этот репозиторий их материалы и конспекты прошлых потоков не входят.

Бот потока - `@jarvis_2_brain_bot`, сайт - `agent.altget.ru` (в `bot/app/bot.py` уже прописаны `VAULT_REPO` и `VAULT_RAW`).

## Правила репозитория

1. Имена файлов - латиница/транслит: URL диктуются голосом со сцены, кириллица в URL ломается в энкодинг.
2. Один файл = одна тема. Не портянки: агент забирает только нужное, лимиты участника не бесконечные.
3. У каждого файла frontmatter с `description` (одна строка) - из них собирается `index.md`.
4. Секретов нет: доступы к моделям, приглашения, пароль Wi-Fi - только через бота.
5. Правки в перерывах: поправил файл -> push -> у всех агентов свежее (`git pull` или raw).
6. Уроки пишутся **для агента участника** (он ведет человека по шагам), формат - `shablony/shablon-uroka.md`.
7. **Любые числа в инструкциях вычитывает человек.** На первом потоке в материалах стояло 8 ГБ RAM вместо реальных 2-4 - правили в эфире, часть зала переплатила.
8. Каталог `.obsidian/` не трогаем: плагины и настройки едут участникам как есть.

## Что изменилось относительно первого потока

- **Ведущий один.** Блоки соведущих (PDF-плейбуки, творческий конкурс дашбордов через v0) из программы и из базы удалены вместе с файлами.
- **Обязательная домашняя подготовка:** софт, сервер на SmartApe, папка JarvisData, Яндекс.Диск и пароль приложения для своей почты - до тренинга. В зале на это времени нет.
- **Подписка на месяц включена в стоимость** вместо ключа с бюджетом на два дня.
- **Практика - спринты с воротами**, а не свободное плавание: на первом потоке 4 часа без чекпоинтов оставили две трети зала позади программы.
- **Кураторов нет.** В текстах вместо «спроси куратора» - «подними руку, подойдет Константин или помощник в зале».
- **Понятийный блок вынесен в первый час** и продублирован текстом: `ponyatiya.md`.
- **Кейс CRM (Битрикс24) и контроль отдела продаж** - явный блок дня 2, показываем живьем.

Источник правды по программе и таймингу - `agent-training/program-v2.md`, разбор первого потока - `agent-training/research/den1-transcript-analysis.md` и `den2-transcript-analysis.md`.
