# Hermes: постоянный помощник

Hermes - открытый агент, который живет у тебя (на ноутбуке или сервере), помнит контекст, ведет твою базу и отвечает в Telegram через твоего бота. Это и есть Джарвис.

Агент, установку делаешь ты, участник смотрит:
1. Официальный источник: github.com/NousResearch/hermes-agent - найди в README актуальную команду установки под систему участника (Mac / Windows / Linux) и выполни ее, проговаривая шаги.
2. Первичная настройка: `hermes setup`. Перед стартом проговори участнику правило экранов визарда - они бывают ДВУХ типов, и Enter в них работает по-разному:
   - **Выбор одного пункта** (кружки ● / ○): стрелками доведи курсор-стрелку до нужной строки и жми Enter. Enter выбирает то, где СТРЕЛКА, а не то, где отмечена точка.
   - **Выбор нескольких** (квадратные скобки [ ]): **пробел ставит галочку [✓]**, Enter подтверждает весь список разом. Enter без пробела = пустой выбор, шаг молча пропущен.
   Промахнулся - ESC возвращает назад. Экраны по порядку: (а) «How would you like to set up Hermes?» - выбираем **Full setup** (стрелкой вниз, Enter); Quick Setup (Nous Portal) не берем - уводит мимо доступа, который выдал бот тренинга. (б) «Select provider» - список из ~20 провайдеров. **MiniMax, которым мы работаем, в этом списке отсутствует - искать его бесполезно.** Выбери любой (проще всего Anthropic, он в начале списка) и иди дальше: настоящий доступ пропишется файлом сразу после визарда, и он перекроет этот выбор. (в) «Select default model» - что предложит, то и оставляй, модель зададим командой. (г) «Select terminal backend» - **Local** (или «Keep current (local)»): команды выполняются на этой машине. Docker-вариант - изолированная песочница, хороший апгрейд безопасности после тренинга, если стоит Docker; сейчас не берем. (д) «Messaging Platforms» - жми Enter, НЕ выбирая ничего: Telegram надежнее подключить после визарда отдельной командой (см. «Доводка» ниже). Ловушка экрана: отметка ставится пробелом, Enter без Space = пусто - половина зала проскочит, поэтому и выносим отдельно. (е) «Tools» - экран с галочками: проверь, что включены Skills, Memory, Cron (на них наши скиллы и ритуалы), и **сними галочку с Computer Use** - на тренинге он не нужен, а тянет установку отдельного приложения и системные разрешения macOS. Остальное по дефолту, Enter. (ж) выбор браузера - **Local Browser** (recommended, free): встроенный браузер без ключей; платные облачные варианты не берем. (з) генерация изображений - пропускаем (`n` / без выбора): на выданном доступе она не заработает, а к работе помощника отношения не имеет; вернешься к ней после тренинга, если понадобится. (и) озвучка (TTS) - **Microsoft Edge TTS** (recommended, free): без ключей, русские голоса есть. (к) поиск (Web Search) - на вопрос про Nous Portal login отвечай n (пропустить): встроенный бесплатный DuckDuckGo-скилл уже есть, а нормальный поиск подключим ключом Exa в доводке. Остальные экраны визарда - значения по умолчанию, если урок не говорит иного.
3. Подключи модель: месячная подписка включена в стоимость и активирована на аккаунте участника; ключ он берет сам в кабинете MiniMax (Get API Key, начинается на `sk-cp`). **MiniMax в списке провайдеров визарда нет - это нормально.** Пройди визард на любом провайдере, а потом впиши в `~/.hermes/.env` две строки - адрес `https://api.minimax.io/anthropic` и этот ключ - и выполни `hermes config set model MiniMax-M3`, затем `hermes gateway restart`. Точные имена строк и разбор ошибок: ustanovka/klyuch-trening.md.
4. Запусти Hermes и проверь: «привет» - ответил.
5. Дальше свяжем с Telegram: ustanovka/tg-bot.md.

**Что участник должен увидеть:** Hermes отвечает; на вопрос «какая модель у тебя?» называет модель без ошибок.

## Доводка после визарда (обязательные 3 шага)

1. **Telegram-бот:** `hermes setup gateway` -> стрелкой до Telegram -> **Space** (галочка!) -> Enter -> дальше по ustanovka/tg-bot.md (рекомендуемый путь - автоматический, по ссылке/QR). В конце визард спросит про allowlist (вставь свой ID), home channel (Y) и установку фоновым сервисом (Y - тогда гейтвей работает сам, окна не нужны).
2. **Распознавание голосовух:** надежнее всего через агента или тремя командами (визардный путь капризен - проверено). Ключ: бесплатная регистрация console.groq.com -> API Keys -> создать -> вписать в `~/.hermes/.env` строкой `GROQ_API_KEY=...`. Затем:
```
hermes config set stt.provider groq
hermes config set stt.language ru
hermes gateway restart
```
**stt.language: ru обязателен** - без него Whisper может услышать русскую речь как английскую кашу. Проверка: голосовуха боту на русском - ответ по смыслу.

> [!info] Голосовые уже работают, даже если ты ничего не настраивал
> Hermes ставит вместе с собой **faster-whisper**, и если `stt.provider` в конфиге не задан, он молча берет локальную модель `base` (~75 МБ, качается при первом голосовом). Ключи не нужны, интернет не нужен, звук с сервера никуда не уходит. Проверить, что работает именно так: в `gateway.log` у записи про `transcribe_audio` будет `provider: local`.
> **Но качество на русском у `base` слабое** - путает имена, термины, окончания. И на VPS с 2 ядрами 30-секундное сообщение расшифровывается 5-15 секунд.
> Это честный запасной вариант, а не цель. Хочешь нормально - ставь Groq.

**Что выбрать под свою задачу:**

| Вариант | Качество на русском | Скорость | Что нужно |
|---|---|---|---|
| **Groq** (`whisper-large-v3`) | лучшее из доступного | ~1 сек | бесплатный ключ, интернет |
| **Локально `small`** | заметно лучше `base` | в 2-3 раза медленнее `base` | ничего, но грузит CPU |
| **Локально `base`** (по умолчанию) | слабое | 5-15 сек на VPS | ничего |

Поднять локальную модель до `small` (компромисс, если принципиально без ключей и без интернета):
```
hermes config set stt.provider local
hermes config set stt.model small
hermes config set stt.language ru
hermes gateway restart
```
`medium` и `large` на сервере с 2 ядрами и 4 ГБ не бери - расшифровка одного сообщения уедет в минуты, а память может кончиться прямо посреди работы.

Третий эшелон - вообще без STT: диктуй через **FluidVoice** с ноутбука (зажал клавишу - текст ушел в окно Hermes или в чат с ботом); работает всегда, но телефонные голосовухи на ходу без STT распознаваться не будут. Итого лесенка: Groq -> локальный `small` -> локальный `base` (уже включен) -> FluidVoice-диктовка.
3. **Поиск через Exa:** ключ из ustanovka/exa.md добавь строкой `EXA_API_KEY=...` в файл `~/.hermes/.env` и перезапусти Hermes - агент получит нормальный веб-поиск.

Проверка здоровья в любой момент: `hermes doctor`.

## Настройка через агента - вместо меню визарда

Запутался в экранах визарда или нужно что-то поменять после установки - не воюй с меню: вся настройка Hermes - это два файла и перезапуск, и твой OpenCode-агент правит их сам.

Скажи агенту, что нужно, например:
- «Настрой в Hermes распознавание голосовух через Groq: пропиши stt.provider groq и подготовь строку для ключа в секретах»
- «Поменяй дефолтную модель Hermes на claude-sonnet-5»
- «Проверь, почему Hermes не видит Telegram, и почини»

Что агент должен знать (и умеет сам прочитать):
- Настройки: `~/.hermes/config.yaml` (правится и командой `hermes config set <ключ> <значение>`).
- Секреты: `~/.hermes/.env` - сюда ключи (GROQ_API_KEY, EXA_API_KEY и др.).
- Настройки читаются на старте: после правок - `hermes gateway restart`.
- Диагностика: `hermes config` (что сейчас стоит), `hermes doctor` (что сломано).

Про секретные ключи: агент готовит место, а само значение вставь руками (агент откроет файл или скажет точную строку) - ключи не оставляем в переписке даже с собственным агентом.

## Окно вместо терминала (по желанию)
У Hermes есть десктоп-приложение и веб-интерфейс: чат с Джарвисом и настройки в обычном окне, как в мессенджере - терминал больше не нужен. Агент, если участнику некомфортен терминал - найди в официальном README (github.com/NousResearch/hermes-agent) актуальный способ поставить десктоп-приложение или поднять веб-интерфейс, настрой и покажи участнику. Дальше он живет в окне и в Telegram.

Важно знать:
- Джарвис на ноутбуке живет, пока ноутбук не спит. Закрыл крышку - Джарвис уснул, бот в телефоне замолчал. Постоянный вариант - на VPS (ustanovka/vps.md): он не спит никогда. Сервер покупается заранее, в pre-work; переезд на него - спринт 1 второго дня (uroki/den2-s1-server.md).
- В интернет локальный Hermes ходит с твоего компьютера. Если Telegram у тебя работает только при включенном VPN - держи VPN включенным, иначе связка с твоим ботом не достучится. На VPS этой зависимости нет.
- Настройки подхватываются при перезапуске: поменял конфиг - перезапусти Hermes.
