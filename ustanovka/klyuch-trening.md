# Ключ тренинга: куда его вставлять

Это канон подключения на этом потоке. Если другой файл волта говорит иначе — верить этому.

Агент, ты ведёшь участника по этому файлу. По одному шагу, после каждого сверяйся с блоком «что участник должен увидеть». Ключ участник вставляет сам — в чат тебе его присылать не надо.

---

## Что вам выдали

Доступ к моделям на месяц входит в стоимость тренинга: организаторы активировали подписку MiniMax **на твоём собственном аккаунте** — том, почту от которого ты присылал в бот. Ключ бот не присылает: ты берёшь его сам в своём кабинете — открой `platform.minimax.io/subscribe/token-plan`, справа блок **Use it with your own tools** → кнопка **Get API Key**. Ключ подписки начинается на `sk-cp`. Модель называется **`MiniMax-M3`** (регистр букв важен).

> [!warning] Три правила про ключ
> - **Никому не пересылайте.** Кто получил ключ — работает от вашего имени и тратит ваш лимит.
> - **Не вставляйте ключ в чат агенту.** Ключ идёт только в файл настроек или в поле настроек приложения.
> - **Не кладите ключ в волт.** Волт синхронизируется — значит всё в нём считайте опубликованным.
>
> Ключ утёк (переслали, вставили в заметку, показали на экране) — скажите ведущему. Отзовём и выдадим новый: две минуты и не стыдно.

---

## Главное: адрес зависит от программы

Ключ один, а адрес сервиса разный. Это не наша прихоть — так устроены сами программы.

| Куда подключаем | Адрес сервиса |
|---|---|
| **Hermes** (помощник на ноутбуке и на сервере) | `https://api.minimax.io/anthropic` |
| **OpenCode** (мастерская) | `https://api.minimax.io/v1` |

Перепутаете — получите «неверный ключ» при полностью правильном ключе. Разберём почему, в шаге про OpenCode.

---

## Шаг 1. Hermes

Адрес заканчивается на **`/anthropic`**.

Агент, открой файл секретов и дай участнику вставить ключ руками:

```
nano ~/.hermes/.env
```

Две строки:

```
ANTHROPIC_BASE_URL=https://api.minimax.io/anthropic
ANTHROPIC_API_KEY=ключ_из_твоего_кабинета
```

Сохранить `Ctrl+O`, `Enter`, выйти `Ctrl+X`. Дальше:

```
hermes config set model MiniMax-M3
hermes gateway restart
```

> [!warning] Ловушка: имя переменной
> В официальных гайдах MiniMax встречается `ANTHROPIC_AUTH_TOKEN`. **У Hermes переменная называется `ANTHROPIC_API_KEY`.** Скопируете гайд дословно — ключ не доедет.

**Что участник должен увидеть:** на вопрос «какая у тебя сейчас модель?» помощник отвечает и называет MiniMax.

### Если ставите Hermes с нуля через визард

На экране «Select provider» MiniMax в списке нет — это нормально. Пройдите визард до конца на любом провайдере, а потом впишите две строки выше: они перекрывают выбор визарда.

---

## Шаг 2. OpenCode

**Простой путь: MiniMax уже есть в списке провайдеров OpenCode.** Проверено КУ на прогоне 17.08.

1. Открой подключение провайдеров.
2. Нажми **«показать больше провайдеров»** - список раскроется, готовые провайдеры прячутся за этой кнопкой.
3. Выбери **MiniMax Token Plan (MiniMax)**.
4. Вставь ключ. Всё: адрес и модель подставляются сами, руками ничего вводить не надо.

**Что участник должен увидеть:** в списке моделей появилась MiniMax, тестовый вопрос получает ответ.

### Запасной путь, если готового провайдера нет в твоей версии

Адрес заканчивается на **`/v1`**, подключается как провайдер **в стиле OpenAI** (OpenAI-compatible), не как Anthropic.

- адрес сервиса: `https://api.minimax.io/v1`
- ключ: тот же, из твоего кабинета MiniMax
- модель: `MiniMax-M3`

> [!danger] Почему нельзя через `/anthropic` — известная ошибка OpenCode
> Если подключить MiniMax к OpenCode как Anthropic-провайдера с нестандартным адресом, **OpenCode теряет ключ по дороге** и отвечает «неверный ключ» (401) — при полностью правильном ключе.
>
> Это [открытый баг самого OpenCode](https://github.com/anomalyco/opencode/issues/21737), не ваша ошибка и не проблема ключа. Чинится одним способом: подключать по OpenAI-пути, адрес `/v1`.
>
> Есть и вторая ловушка того же рода ([#5674](https://github.com/anomalyco/opencode/issues/5674)): адрес нужно указывать **в поле адреса самого провайдера**, а не в дополнительных параметрах — иначе он тоже не доедет.
>
> Готовый провайдер из списка обходит обе ловушки — поэтому он и основной путь.

---

## Шаг 3. Проверка за минуту

1. Ключ на месте, имя переменной совпадает с тем, что написано выше.
2. Hermes перезапущен после правки (без перезапуска живёт старая настройка).
3. Помощник отвечает на простой вопрос.
4. **Главное:** попросите сделать что-нибудь с файлами — «создай файл `proba.md` и напиши в него сегодняшнюю дату». Файл появился — всё работает.

Четвёртый пункт главный. Модель может отвечать в чате, но не уметь пользоваться инструментами через выбранный адрес — тогда агент бесполезен, и ловить это надо сразу, а не через час.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| OpenCode: «неверный ключ» / 401, хотя ключ свежий | Подключили по Anthropic-пути. Переподключите как провайдера в стиле OpenAI, адрес `https://api.minimax.io/v1` |
| Hermes: ошибка авторизации | Проверьте имя переменной: нужно `ANTHROPIC_API_KEY`, а не `ANTHROPIC_AUTH_TOKEN` |
| «Модель не найдена» | Идентификатор пишется `MiniMax-M3`, регистр букв важен |
| Ошибка 429 / «rate limit» | Слишком много запросов разом. Отпускает примерно за минуту. Повторяется — остановите лишних агентов и скажите ведущему |
| Ответ приходит, но файлы не создаются | Адрес перепутан местами между программами. Сверьтесь с таблицей вверху |
| Отвечает, но не помнит, кто вы | Это не про модель — не подключён волт. Смотрите `ustanovka/sinhronizaciya-volta.md` |
