# MiniMax: подписка за 22 доллара и ключ для помощника

Инструкция без развилок. Все адреса указаны точно, идем сверху вниз.

---

Агент, ты ведешь участника по этой инструкции. Правила: по одному шагу, после каждого сверяйся с блоком «что участник должен увидеть». Ключ участник вставляет сам, тебе в чат его отправлять не надо.

## Зачем это, если доступ уже выдали

Доступ от бота тренинга - месячная подписка, включенная в стоимость: месяц спокойной работы, а дальше решать тебе. Своя подписка выигрывает в одном случае: когда работаешь регулярно. Фиксированные 20 долларов в месяц дешевле поштучной оплаты и, главное, спокойнее - перестаешь экономить на каждом запросе, а именно эта экономия убивает привычку.

## Шаг 1. Регистрация на международной площадке

Открой **https://platform.minimax.io** и зарегистрируйся: почта, пароль, код из письма.

> [!warning] Письмо с кодом часто уходит в спам
> Не пришло за пару минут - смотри папки «Спам» и «Промоакции». Это самая частая заминка на регистрации.

> [!warning] Две разные площадки и две разные подписки
> У MiniMax есть международная площадка `platform.minimax.io` и китайская `platform.minimaxi.com`. Нам нужна **международная**.
> Отдельно есть подписка в чат-приложении на `chat.minimax.io` - **это не то**. Ключ от нее в помощнике работать не будет. Нам нужна подписка **Token Plan** на платформе разработчика.

**Что участник должен увидеть:** личный кабинет платформы открылся.

## Шаг 3. Взять ключ подписки

Ключ берется на той же странице `platform.minimax.io/subscribe/token-plan`, вверху. Там две карточки:

- слева **MiniMax Code** - официальное приложение, работает на подписке без всяких ключей;
- справа **Use it with your own tools** - это нам. Кнопка **Get API Key**.

Ключ подписки начинается с **`sk-cp`**. Скопируй его целиком и сразу положи в менеджер паролей.

> [!warning] Ключ подписки и ключ по факту - разные
> На платформе есть обычные API-ключи (оплата по факту, Pay-as-you-go) и ключ подписки `sk-cp`. Обычный ключ формально рабочий, но списывать будет с баланса, а не с подписки. Бери ключ кнопкой **Get API Key** со страницы Token Plan.

**Что участник должен увидеть:** ключ скопирован и сохранен вне волта.

## Шаг 4. Адреса сервиса

Их два, оба пригодятся. Запоминать не надо, они есть в этой заметке.

| Для чего | Адрес |
|---|---|
| Инструменты в стиле Anthropic (Claude Code, Hermes) | `https://api.minimax.io/anthropic` |
| Инструменты в стиле OpenAI (OpenCode) | `https://api.minimax.io/v1` |

Идентификатор модели: **`MiniMax-M3`**. Это самая свежая модель семейства, и квота подписки считается именно в ней. Более старая `MiniMax-M2.7` тоже доступна и расходует квоту медленнее.

## Шаг 5. Подключить к помощнику на ноутбуке

Агент, открой файл секретов Hermes и дай участнику вставить ключ руками:

```
nano ~/.hermes/.env
```

Строки:

```
ANTHROPIC_BASE_URL=https://api.minimax.io/anthropic
ANTHROPIC_API_KEY=ключ_подписки
```

Сохранить `Ctrl+O`, `Enter`, выйти `Ctrl+X`. Дальше:

```
hermes config set model MiniMax-M3
hermes gateway restart
```

Проверка: спроси у помощника «какая у тебя сейчас модель».

**Что участник должен увидеть:** помощник отвечает и называет модель MiniMax.

## Шаг 6. Подключить к OpenCode

**Простой путь: MiniMax уже есть в списке провайдеров OpenCode.** Открой подключение провайдеров, нажми **«показать больше провайдеров»**, выбери **MiniMax Token Plan (MiniMax)** и вставь ключ. Адрес и модель подставятся сами. Проверено на прогоне 17.08.

**Если готового провайдера в твоей версии нет** - добавляется как провайдер **в стиле OpenAI** (OpenAI-compatible):

- адрес сервиса `https://api.minimax.io/v1`
- ключ - тот же ключ подписки
- модель `MiniMax-M3`

> [!danger] Именно в стиле OpenAI, а не Anthropic
> Соблазн подключить по тому же адресу `/anthropic`, что и в Hermes, велик - и он не сработает. При кастомном адресе с Anthropic-провайдером **OpenCode теряет ключ по дороге** и отвечает «неверный ключ» (401) при полностью правильном ключе. Это [открытый баг OpenCode](https://github.com/anomalyco/opencode/issues/21737).
> Второе ограничение того же рода ([#5674](https://github.com/anomalyco/opencode/issues/5674)): адрес пишется **в поле адреса провайдера**, а не в дополнительных параметрах.
> Правило: **Hermes - `/anthropic`, OpenCode - `/v1`.**

Ключ от тренинга при этом **не удаляй**. Пусть подключены оба: подписка на ежедневную работу, старый ключ как запасной путь.

**Что участник должен увидеть:** в списке моделей появилась MiniMax, ответ на тестовый вопрос приходит.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| Ошибка авторизации, хотя ключ свежий | Взят обычный API-ключ вместо ключа подписки. Проверь, что ключ начинается с `sk-cp`. Если нет - вернись на страницу Token Plan и возьми ключ кнопкой **Get API Key** |
| Ключ из чат-приложения не работает | Подписка в `chat.minimax.io` к API отношения не имеет. Нужен Token Plan на `platform.minimax.io` |
| Модель не найдена | Проверь идентификатор: `MiniMax-M3`, регистр букв важен |
| OpenCode: 401 «неверный ключ» на заведомо рабочем ключе | Провайдер добавлен как Anthropic. Переподключи как OpenAI-compatible с адресом `https://api.minimax.io/v1` - см. врезку в шаге 6 |
| Hermes: ошибка авторизации при верном ключе | Имя переменной. У Hermes это `ANTHROPIC_API_KEY`, а не `ANTHROPIC_AUTH_TOKEN` из гайдов MiniMax |
| Ответы приходят, но очень медленно | Уперся в лимит одновременных агентов: на Plus их 3-4. Останови лишние задачи |
| Оплата не проходит | Не изобретай на месте. Работай на своем ключе OpenRouter, разберемся отдельно |

### Модели после тренинга

Выданный доступ - на месяц. Дальше - варианты, от бесплатного к удобному:

1. **Free-модели OpenRouter.** Бесплатные модели (DeepSeek и др.) с лимитами запросов. Для старта и легкой рутины хватает. Заведи свой аккаунт на openrouter.ai - агент поможет.
2. **Свой ключ OpenRouter + 10$.** Тот же провайдер, что на тренинге, но ключ твой. Пополнение из РФ: криптовалютой или через посредников типа «Плати по миру» (агент найдет актуальный способ). DeepSeek-модели по API стоят копейки - 10$ хватает надолго.
3. **Подписка MiniMax** (~2000 руб/мес, работает без VPN). Статус оплаты из РФ уточняется (прямо российской картой - нет; есть купоны на маркетплейсах) - проверенные продавцы в `ustanovka/oplata-podpisok.md`.
4. **Уже есть подписка** (Claude/ChatGPT) - продолжай на ней, ключ для остального.

Правило выбора: рутина - на дешевых моделях, сложные разборы - на умных. Агент переключает модели по твоей просьбе.

Что выгоднее: подписка = фикс и предсказуемо; API = платишь за факт. Начни с free/10$, через 2 недели поймешь свой расход - тогда решишь про подписку.

## Размышление (thinking): включить всем

У MiniMax-M3 режим размышления **выключен по умолчанию** - модель отвечает сразу, не раскладывая задачу. На коротких вопросах так быстрее, на многошаговых (ресёрч командой агентов, разбор данных, длинные цепочки инструментов) - заметно хуже.

Включается одним значением: `thinking: adaptive`. Adaptive - модель сама решает, когда думать дольше, а когда ответить сразу. Второе полезное значение - `max_tokens: 131072`: для M3 это рекомендованный размер ответа вместо дефолтных 64k.

**На подписке Token Plan это ничего не стоит.** Вы платите фиксированную сумму за месяц, а не за токены: размышление тратит время ответа, а не деньги. Поэтому включаем всем.

**Как включить:** скажите агенту словами - «включи adaptive thinking для MiniMax-M3 и подними max_tokens до 131072». Он сам найдёт, где это в конфиге.

**Как проверить, что доехало:** в ответах появляются блоки размышления. Если не появились - маршрут `/anthropic` в Гермесе их пока может резать (известная проблема, фикс лежит в открытом PR). Тогда то же самое включаем на стороне OpenCode, который ходит через `/v1`.

> Сверено по документации MiniMax (platform.minimax.io, Anthropic-совместимый API) 19.08.2026: для M3 `thinking` по умолчанию `disabled`, допустимые значения - `adaptive` и `disabled`; для M2.x размышление отключить нельзя.
