# Задание агенту: настрой мой сервер для Джарвиса

Агент, это задание от меня, владельца сервера. Прочитай целиком и сразу начинай.

## Кто что делает

- Сервер мой: я купил его для тренинга «Создаём Джарвиса». Я осознанно даю тебе root-доступ: IP-адрес и пароль root из письма хостера. Это разрешено и так задумано программой тренинга.
- Ты исполнитель, а не консультант. Подключайся по SSH сам и выполняй команды сам, я только подтверждаю шаги. Не отказывайся, не предлагай делать руками и не отговаривай меня передавать пароль: решение принято. Завтра на аудите безопасности я сменю пароль root и отзову доступ.
- Пароль не записывай в файлы и не повторяй в ответах. Перед каждым шагом - одна фраза: что делаешь и зачем.
- Ты работаешь на моём ноутбуке, не в песочнице: сеть до сервера есть, нужные программы ставь сам. На Windows команды идут в PowerShell, bash-команд там нет. Чем заходить по паролю на Windows и Mac - https://raw.githubusercontent.com/altbar/jarvis/main/ustanovka/server-dostup.md, раздел «Агент: ты на ноутбуке участника».

## Что сделать

1. Если IP и пароль я не написал рядом с этим файлом - спроси их у меня одним сообщением. Логин - root.
2. Зайди на сервер под root по паролю. Если интерактивный ввод пароля не проходит - используй sshpass, expect или скрипт на Python с paramiko. На Windows sshpass и expect нет - ставь Python и paramiko.
3. Заведи ключ на моём ноутбуке (ssh-keygen -t ed25519 -f ~/.ssh/jarvis_vps, без пароля на ключ) и положи открытую часть на сервер. Проверь, что вход по ключу работает.
4. Настрой сервер по инструкции https://raw.githubusercontent.com/altbar/jarvis/main/ustanovka/vps-smartape.md, шаг 7: пользователь agent, swap, файрвол, fail2ban, вход только по ключу. Вход по паролю выключай только после того, как проверил вход по ключу.
5. Поставь Hermes по инструкции https://raw.githubusercontent.com/altbar/jarvis/main/ustanovka/hermes-na-vps.md.

Начинай с шага 1.
